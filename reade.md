# 🎓 Student Management System

A simple and structured **Student Management System** designed to manage student-related operations through a clean and organized web interface.

The project is built with a separated structure for **pages, controllers, and styling**, making the codebase easier to understand, maintain, and extend.

---

## ✨ Overview

**Student Management System** is a web-based project created to provide a simple foundation for managing student information.

The project separates the application into different layers:

* 📄 **Pages** — Application pages and user interface
* ⚙️ **Controllers** — Application logic and request handling
* 🎨 **Styles** — Styling and visual presentation

This structure helps keep the project organized and makes future development easier.

---

## 🚀 Features

* 👨‍🎓 Student management
* 📄 Organized application pages

## 🧩 Architecture

The project follows a simple separation-of-concerns approach:

```text
                ┌─────────────────┐
                │      Pages      │
                │   User Interface│
                └────────┬────────┘
                         │
                         ▼
                ┌─────────────────┐
                │   Controllers   │
                │ Application Logic
                └────────┬────────┘
                         │
                         ▼
                ┌─────────────────┐
                │     Backend     │
                │ / Data Handling │
                └─────────────────┘

                ┌─────────────────┐
                │     Styles      │
                │  UI Presentation│
                └─────────────────┘
```
